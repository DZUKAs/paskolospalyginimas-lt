# 2 etapas — dizaino sistema

Šilta balta #F7F7F0, tamsi miško žalia #183D32, laimo akcentas #D5F67B. Tamsioji tema naudoja #10271F foną ir #F1F5E8 tekstą. Tekstas ant laimo visada tamsus. CSS kintamieji apibrėžia semantinę spalvų sistemą.

Vietinis Manrope su lotynų išplėstiniu raidynu, sklandus antraščių dydis, 1200 px turinio riba, 16–24 px mobilūs paraštės, 18–24 px kortelių kampai. Pagrindinė kompozicija: redakcinis hero ir skaičiuoklė, kreditorių juosta, trys pasiūlymų kortelės, tamsus veiksmų blokas, gidas, DUK.

Klaviatūros fokusas, perėjimas prie turinio, semantinės formų žymos, detalėmis išskleidžiami DUK, reduced-motion palaikymas. Iliustracija originali, geometrinė, sugeneruota vietoje ir eksportuota WebP. Kreditorių pavadinimai nėra išgalvoti prekių ženklų logotipai; tikrus logotipus galima įkelti administravime.
